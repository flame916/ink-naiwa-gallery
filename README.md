# 墨韵蛙影 · 丹青幻境（Ink & Naiwa Gallery）

一座融合**中国传世水墨古画**与**奶蛙（Naiwa）形象**的交互式动态肖像画廊。保留原版奶蛙标志性神态与宋明纸本/绢本水墨笔韵，游标轻拂即活、点印可勘真迹。

## 本地运行

纯原生 HTML / CSS / JavaScript + Canvas + Web Audio API 实现，零构建依赖：

```bash
python -m http.server 8765
```

浏览器访问 `http://localhost:8765` 即可体验。
